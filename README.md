### Welcome to my GitHub profile! 
I'm a passionate developer, constantly exploring new technologies. Like other engineers, I find enjoyment in making things work again. If you are like me and get unsettled with something broken, join me. Together, we can fix a lot out there, one patch at a time. 

Currently, I'm working on some really fun SOC projects. Come back later when I have more to share.

You may ask, where are my repos? I keep most of them self-hosted on GitLab on-premises. The saying "anything you type on the web stays on the web" is true. A simple example are all the API keys leaked on the web now a days. For personal and professional reasons, I'll keep most projects private. If you want to see more of my work, contact me, and I'll give you access to my private GitLab repos.
